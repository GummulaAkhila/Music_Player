# Music Player Web Application

## About the Project

A simple and interactive music player web application built using HTML, CSS, and JavaScript. It provides an intuitive interface for playing and controlling audio tracks.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Play and pause functionality
* Next and previous track controls
* Audio playback
* Interactive music player interface
* Track information display
* Responsive layout

## Project Structure

```text
Music-Player/
├── index.html
├── style.css
├── script.js
└── assets/
    └── music/
```

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select a track and use the playback controls.
